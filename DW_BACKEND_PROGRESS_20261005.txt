Live testing found an error that protocol-only testing initially missed:
PING's final byte is ORIGIN, not request/reply. Replay originates1 every10seconds;
1 must be echoed unchanged. Origin0 is a server probe that the client echoes.
The incorrect provider answered only0, causing native rebinds after30seconds.
The corrected build held one native association for305seconds/30ping echoes
before the subsequent worker-failure hardening. Final deployment requires its
own fresh stability receipt; historical hashes are never relabeled.

Worker rejects malformed/foreign/replayed packets without terminating other
routes. Socket wait/send or durable event write failure withdraws advertisement,
clears active routes and exposes a bounded diagnostic failure label. Typed
transport failures derive from std::exception so startup rollback handles them.
