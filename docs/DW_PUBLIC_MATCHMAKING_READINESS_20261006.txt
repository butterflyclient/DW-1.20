Implementation
Public task 145/18 previously created separate lobbies for compatible players.
It now fills a live compatible public lobby first, using the bounded current
assignment index. The host must still own that assignment and have a live
authenticated session. Playlist/catalog data, native rules and versions,
capacity, privacy, host state and join-in-progress policy must match.

Public and explicit presence joins share one assignment implementation. It
preserves the existing host address and DTLS material, updates the documents,
publishes lobby/search/current-index snapshots atomically, keeps a joining
party on one least-populated team, and sends recovered event 2001 to joiners
and event 2006 to existing members. Each joining party has its own search ID.
Join-existing-only searches fail unavailable rather than creating a new game.

Malformed capacities, invalid live-party tokens, private/closed/full lobbies,
stale owner assignments and incompatible publications fail before any lobby,
search or assignment index changes. Historical unmarked lobbies are never
implicitly reclassified as public.
