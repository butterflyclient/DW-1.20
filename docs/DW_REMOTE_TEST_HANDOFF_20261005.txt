LOCAL IDENTITY AND NAME
Created automatically on first launch:
%LOCALAPPDATA%\ReplayDW\player-identity.bin
The private P-256 key is protected with Windows user DPAPI and stays on the
player's machine. The backend stores metadata by public-key fingerprint under
data\platform-client-profiles. Universal and game IDs remain stable across full
game/backend restarts, EXE replacement and renames. Do not distribute or delete
the identity file to change your name. A corrupt/inaccessible identity fails
sign-in rather than replacing the account. A complete interrupted first-launch
save is recovered.

Optional INI field: player_name=YourName
Names are unique between automatic player accounts, ignoring case, with 1..35
printable ASCII characters excluding #, % and leading/trailing spaces. Blank
creates a unique ReplayPlayer-<fingerprint> name on first registration; later
blank names keep the saved name. Changing player_name renames the same account
on the next full launch. Legacy fixture names cannot block or shadow automatic
accounts. Legacy profile/access_key fields are ignored by this EXE.
